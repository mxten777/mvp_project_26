


# Resort BAIKAL — 프리미엄 리조트 플랫폼 제안서

---

## 1. Why Resort BAIKAL? (Why Now?)

- **글로벌 여행 시장의 변화와 기회**  
	팬데믹 이후, 전 세계 리조트·호텔 예약 시장은 연평균 8% 이상 성장(Statista, 2025 전망)하며, 모바일 예약 비중이 60%를 돌파했습니다.  
	고객은 빠르고 신뢰할 수 있는 예약 경험, 운영자는 실시간 데이터 기반의 효율적 관리와 분석 도구를 요구합니다.

- **경쟁사와의 차별화**  
	기존 OTA(Agoda, Booking 등)는 대형 플랫폼 중심, 개별 리조트의 브랜드 경험·실시간 운영 최적화에는 한계가 있습니다.  
	Resort BAIKAL은 브랜드 일관성, 실시간성, 모바일 UX, 운영자 도구까지 한 번에 제공합니다.

- **Resort BAIKAL의 미션**  
	“고객에게는 최고의 예약 경험, 운영자에게는 실시간 관리 혁신을 제공한다.”

---

## 2. 시장의 Pain Point & 우리의 솔루션

- **고객 Pain Point**
  - 복잡한 예약 과정, 느린 응답, 모바일/PC 간 불편함
  - 예약 후 변경·취소의 번거로움, 신뢰 부족, 브랜드 경험의 일관성 결여

- **운영자 Pain Point**
  - 실시간 예약/취소 알림 부재, 데이터 분산, 수기 관리
  - 객실 가동률·매출 등 핵심지표 실시간 파악 어려움, 마케팅/고객관리 도구 부족

- **Resort BAIKAL의 솔루션**
  - 단계형 예약 위저드, 실시간 가용성·예약 현황 제공, 예약 변경/취소 자동화
  - 관리자 대시보드(예약/매출/가동률), 실시간 알림, CSV 내보내기, 고객 관리 기능
  - PWA 기반 오프라인 지원, 모바일 홈화면 설치, 브랜드 맞춤형 UI/UX

## 3. 주요 기능 및 차별화 포인트

- **프리미엄 브랜드 경험**
	- 통일된 퍼플 테마, 고급 타이포그래피, 세련된 UI/UX
	- Framer Motion 기반 부드러운 애니메이션, Skeleton/Spinner로 체감 성능 극대화
	- 브랜드별 맞춤형 테마 및 로고 적용 지원(확장성)

- **모바일 퍼스트 & 접근성**
	- 터치 최적화(44px), 반응형 레이아웃, ARIA/키보드 네비게이션
	- 라이트/다크 자동 전환 및 사용자 토글, 접근성 표준 준수

- **실시간 운영성**
	- Firebase 실시간 동기화(예약, 취소, 변경 즉시 반영)
	- 관리자 권한 세분화, 푸시 알림(예정), 데이터 내보내기, 실시간 통계

- **콘텐츠·미디어 최적화**
	- Firebase Storage 기반 이미지 업로드/최적화, 지연 로딩
	- SEO 및 소셜 공유 최적화(예정), SNS 공유 버튼

- **비즈니스 모델 및 확장성**
	- SaaS(구독형)·커스터마이징·제휴 리조트 확장 지원
	- API/OTA 연동(예정), 글로벌 다국어 지원(예정)

## 4. 기술 아키텍처 & 성능

- **Frontend**: React 19, Vite, TailwindCSS, React Router
- **Backend**: Firebase Auth, Firestore, Functions, Storage
- **배포/호스팅**: Vercel, PWA(Service Worker)
- **성능**:  
  - Vite 기반 번개같은 빌드/배포(개발→배포 1분 이내)  
  - Firestore 리스너로 실시간 UI(예약/취소/변경 1초 이내 반영)  
  - 코드 스플리팅, 이미지 최적화로 초기 로딩 < 1초, Lighthouse 95점 이상 목표

## 5. 실제 서비스 시나리오

1. **고객**  
	- 모바일에서 3단계로 객실 예약 → 실시간 가용성 확인 → 예약 완료/변경/취소까지 1분 이내  
	- 예약 내역, 결제(예정), 푸시 알림까지 원스톱
	- 브랜드별 맞춤형 UI, SNS 공유, 오프라인 환경에서도 예약 내역 확인 가능

2. **운영자**  
	- 대시보드에서 실시간 예약/매출/가동률 확인  
	- 예약/사용자/리뷰 관리, CSV 내보내기, 고객별 통계/분석
	- 실시간 알림으로 빠른 대응, OTA/API 연동(예정)
